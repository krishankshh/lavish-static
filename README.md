# Lavish - Static Client Preview

This repository contains the standalone, pixel-perfect static export of the **Lavish** website, ready for 1-click deployment on [Netlify](https://netlify.com), [Cloudflare Pages](https://pages.cloudflare.com), or [Vercel](https://vercel.com).

## Deployment Instructions (Netlify)
1. Log into your Netlify dashboard.
2. Click **Add new site** > **Import an existing project**.
3. Select **GitHub** and choose the `lavish-static` repository.
4. Leave build settings as default:
   - **Build command:** *(leave empty)*
   - **Publish directory:** `.`
5. Click **Deploy lavish-static**.
